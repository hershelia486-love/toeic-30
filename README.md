# toeic-30
# TOEIC 30 — 380에서 920으로

30일 독학 스케줄 기반 TOEIC 학습 웹앱입니다. 단일 HTML 파일로 동작하며 별도 설치나 서버가 필요 없습니다.

## 주요 기능

- **30일 스케줄러**: 시작일을 설정하면 Day1~30이 자동으로 배정되고, 완료 여부를 기록합니다.
- **단어 학습**: Day별 단어(콜로케이션 + 연상 암기법 포함)를 플래시카드로 학습하고, 단어/예문 듣기(음성 재생)가 가능합니다.
- **문제 풀이**: Day별 LC/Part5/Part6/Part7 문제를 바로 풀고 채점합니다.
- **실전모의고사 타이머**: Day21·23·25·27·29에 LC/RC 시간 제한 모의고사를 제공합니다.
- **오답노트**: 틀린 문제를 유형별로 저장하고, 가장 많이 틀리는 유형을 자동으로 집계합니다.

## 사용 방법

1. `index.html` 파일을 브라우저(Safari, Chrome 등)에서 직접 엽니다.
2. 학습 데이터는 브라우저의 localStorage에 저장되며, 별도 로그인이나 서버가 필요 없습니다.
3. 학습 기록을 초기화하려면 스케줄 탭 하단의 "전체 학습 초기화" 버튼을 사용하세요.

## 배포

이 프로젝트는 정적 HTML 파일이라 별도 빌드 과정 없이 [Vercel](https://vercel.com)이나 GitHub Pages 등에서 바로 배포할 수 있습니다.

## 기술 스택

- 순수 HTML / CSS / JavaScript (외부 라이브러리 없음)
- 브라우저 내장 Web Speech API를 이용한 음성 재생
- localStorage 기반 데이터 저장
